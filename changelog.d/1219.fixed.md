  a letter, so `password` with `U+00AD` and `U+0336` after each letter read clean while `canonicalize` returned
  a struck `password` that reports `zalgo`. A format or private-use character draws nothing and no longer closes
  a letter. The overlay rule also reads the canonical form of a text holding an overlay mark, so `|` and
  `U+2103`, which `canonicalize` folds to letters, report too, and every scalar value as the filler now gives
  the input and its canonical form one verdict. A mark on a symbol still counts for no letter, so `a=` `U+0338`
  `b` stays the negation it is. The detector now links the preset engine, so a Wasm build holding only
  `has_anomalies` grows from 439,293 to about 557,000 bytes.
