# Changelog archive

Releases 0.14.1 back to 0.1.0, moved out of `CHANGELOG.md` so that the main
[changelog](../CHANGELOG.md) stays short enough to read. Each page holds one minor
series, copied verbatim: this is history, so entries keep the issue numbers, names and
wording they shipped with, and are never re-flowed or corrected.

The main changelog keeps every release from 0.15.0 on. That is where the cut falls
because 0.15.0 introduced `KEY_SCHEMA_VERSION`, so every upgrade note that says whether a
stored key moved is still on the main page.

Entries from before the rename (#264) use the old identity: `translit-rs` on PyPI, the
`translit` import package and the `_translit` native module.
