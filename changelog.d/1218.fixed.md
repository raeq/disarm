- **A private-use character that splits a word reports (#1212).** `pay` + `U+E000` + `pal` read clean while
  `canonicalize` returned `paypal`, and so did `password` with `U+E000` after each letter, below both the run
  rule and the spread rule. One, or a touching run of up to three, between two Latin letters of the same case
  now reports `invisible`, and eight between any other letters report unless a letter on either side is CJK.
  A glyph beside a letter keeps #812's answer, so `Menu` + `U+E000` stays clean, and so does a glued label
  that changes case at the join, such as `Save` + `U+E001` + `File`. `Pay` + `U+E000` + `Pal` stays clean as a
  stated cost, and `is_canonical` still answers for it.
