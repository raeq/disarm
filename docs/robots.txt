# conventional path to find any of the pages it lists.

# had none. That file carried the Content Signals explanatory preamble and no
# directives whatsoever -- no User-agent, no Allow, no Disallow and no Sitemap --
# so nothing operative is being revoked here. To express signals deliberately,
# add `Content-Signal:` lines under the User-agent group above; declaring none
# leaves the position unstated, which is what the managed file already did.
